3. The Instrument Error app and YouTube API Services

The Instrument Error app uses YouTube API Services.

The app is the channel's own production tool. It runs only on our own computer, it is used only by us, and it is not offered to the public. Nobody else signs in to it.

Because the app uses YouTube API Services, its use is subject to the YouTube Terms of Service (https://www.youtube.com/t/terms). How Google itself handles data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

How rules written for public apps apply to a one-person tool

The YouTube API Services Developer Policies are written for apps that members of the public sign in to. Some of their requirements, such as accepting a privacy policy before first use or asking an app to delete your stored data, assume users other than the developer. This app has no such users, so the sections below say how each requirement applies to it instead of describing features that do not exist.

For example, there is no sign-up screen. The app's only user is us, and this policy is published at a fixed address that is linked from every page of this website.

4. What the app accesses

The app holds two read-only permissions (OAuth scopes) and uses them for our own channel only:

https://www.googleapis.com/auth/youtube.readonly
Reads the channel's video details and public statistics: view, like and comment counts.
https://www.googleapis.com/auth/yt-analytics.readonly
Reads YouTube Analytics reports for the channel, for example engaged views, average percentage viewed and subscribers gained.

The app collects no data about viewers or about any other Google user. It does not hold the upload permission (youtube.upload) or any other permission that could change anything on YouTube.

5. How the data is used

The app uses what it reads for one purpose: to judge which of the channel's videos work. The data is not used for advertising or for any other purpose.

6. Storage and security

  • Sign-in tokens are stored on our own computer, encrypted with Windows DPAPI (the Windows Data Protection API), so that only our own Windows account can read them.
  • Channel data the app reads (video details, statistics and analytics reports) is kept in a local database on the same computer.
  • Sign-in happens on Google's own pages. The app receives a token from Google and never sees or stores a Google password.
  • The app connects to Google's APIs over encrypted HTTPS.

7. Sharing

Nothing the app reads is sold, shared or used for advertising. It is not shown to anyone but us, and no third party serves content or advertisements through the app or this website.

8. Keeping, deleting and revoking access

How long data is kept

The sign-in token is kept only while the app needs it to read the channel. Channel data is kept only for as long as it is needed to judge which videos work.

Deleting stored data

Our normal procedure is to delete the stored token and the local channel data once they are no longer needed. Because the app's only user is us, there is no delete button: we delete the data ourselves. If you believe the app holds data about you, email [CONTACT EMAIL] and we will delete it as soon as possible and within 7 days.

Deleting data stored by the app does not affect anything stored by YouTube. To delete data on YouTube itself, use YouTube (for example, YouTube Studio) or another authorised app that can delete it.

Revoking access

In addition to that procedure, access can be revoked at any time on the Google security settings page, https://security.google.com/settings/security/permissions, which opens the permissions page of a Google Account (myaccount.google.com/permissions). Once access is revoked, the app can no longer read the channel, and we delete the data it stored under that permission as soon as possible and within 30 days.
