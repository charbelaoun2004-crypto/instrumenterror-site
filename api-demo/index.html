What the screencast shows, step by step

  1. Authorisation. mm analytics auth --check shows the stored OAuth 2.0 grant the channel owner gave on Google's consent screen: authorised, refresh token stored, OAuth app status production, and the three scopes above. The token itself is stored encrypted (Windows DPAPI) and never shown.
  2. The video. An original Short made for the channel (MM-0004 version 9, "The students who ran past a staged fight without noticing it"): its script is fact-checked against cited peer-reviewed sources, it is rendered to a 1080x1920 H.264/AAC file, and its approval is bound to the file's SHA-256, so only the approved file can be uploaded.
  3. Upload. mm publish demo-upload --video MM-0004 --version 9 calls videos.insert with part=snippet,status and a resumable media upload. The request sets the title, the description (with the sources and the AI disclosure sentence), category 22, language en, privacyStatus: private, selfDeclaredMadeForKids: false and containsSyntheticMedia: true, with no subscriber notification. YouTube answers with the new video id (Z3PIlbMxCIw).
  4. Read-back. The client calls videos.list with part=snippet,status for that id and compares what YouTube holds with what was sent: title, channel, privacy status, upload status and made-for-kids all match.
  5. End result. The same video in YouTube Studio: on the Instrument Error channel, private, with the title and description the client sent.

How it runs in normal operation

Each finished and approved Short is uploaded exactly as above, except that status.publishAt is set to the next free posting slot (08:00, 14:00 or 20:00 Sydney time, at most three a day), so YouTube itself publishes it at that time. Every upload is made once per approved file (an idempotency token prevents a second upload of the same file), and every upload is read back with videos.list. Expected usage is about 4,800 quota units a day for three uploads plus a few hundred units of read-backs, within the default quota.

The upload above was made for this demonstration and has the prefix "[API DEMO]" in its title; it stays private.
